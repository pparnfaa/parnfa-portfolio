## Tech ที่ใช้

| เครื่องมือ | ใช้ทำอะไร |
| --- | --- |
| React 19 | UI |
| TypeScript | type safety |
| Vite | dev & build |
| Tailwind CSS v4 | สไตล์ |

---

## รันโปรเจกต์

```bash
# ติดตั้ง dependencies
npm install

# เปิดโหมดพัฒนา
npm run dev

# build สำหรับ production
npm run build

# ดูผลหลัง build
npm run preview
```

เปิดลิงก์ที่ Vite แสดงในเทอร์มินัลได้เลย (โดยปกติคือ `http://localhost:5173`)
